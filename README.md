## K-Nearest Neighbor - Diabetes Classification
A Machine Learning implementation of the K-Nearest Neighbor algorithm using Python and Scikit-learn to classify data from the Diabetes dataset.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Google Colab

## Dataset
Diabetes Dataset.

## Workflow
1. Dataset Loading
2. Data Preparation
3. Feature Selection
4. Splitting the Dataset
5. K-Nearest Neighbor Model
6. Model Training
7. Prediction
8. Correct Predictions
9. Wrong Predictions

## Purpose
This repository demonstrates K-Nearest Neighbor classification using the Diabetes dataset and identifies both correct and incorrect predictions made by the model.
